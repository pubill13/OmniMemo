# 포함 글꼴

글꼴은 Windows에 설치하지 않고 OmniMemo 내부 리소스로 제공합니다. 기존 메모의 기본 글꼴은 변경하지 않습니다. 모든 파일은 수정하지 않은 Regular 정적 OTF/TTF이며 SIL Open Font License 1.1로 배포됩니다. 각 저작권 고지와 라이선스 전문은 배포 폴더 `Assets/Fonts/*txt`에 포함됩니다.

| 메뉴 이름 | 공식 출처 | 파일 |
|---|---|---|
| Pretendard · 프리텐다드 | [orioncactus/pretendard v1.3.9](https://github.com/orioncactus/pretendard/tree/v1.3.9) | Pretendard-Regular.otf |
| 나눔고딕 | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/nanumgothic) | NanumGothic-Regular.ttf |
| 나눔명조 | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/nanummyeongjo) | NanumMyeongjo-Regular.ttf |
| 나눔손글씨 펜 | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/nanumpenscript) | NanumPenScript-Regular.ttf |

Pretendard는 Kil Hyung-jin 및 해당 라이선스의 기반 글꼴 저작권자, 나눔 글꼴은 NHN Corporation의 저작물입니다. 원본 파일과 라이선스 취득일: 2026-10-02. 원본 저작권과 Reserved Font Names는 각 동봉 라이선스를 따릅니다.

메모 메뉴의 `설치된 글꼴 더 보기…`에서는 이 PC에 이미 설치된 글꼴을 이름으로 검색하고 미리 볼 수 있습니다. 해당 글꼴 파일은 앱에서 수집하거나 재배포하지 않습니다. 다른 PC에서 찾을 수 없는 글꼴은 맑은 고딕으로 표시하되 저장된 선택 이름은 유지합니다.
