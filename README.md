# OmniMemo

Windows 개인용 로컬 스티커 메모입니다. .NET 10 / WPF / SQLite 기반이며 계정이나 서버가 필요하지 않습니다.

## 실행

GitHub 릴리스의 `OmniMemo-1.12.2-win-x64.zip`을 풀고 `OmniMemo.exe`를 실행하세요. 런타임이 포함되어 별도 .NET 설치가 필요하지 않습니다. 업데이트할 때는 트레이에서 기존 앱을 종료한 뒤 새 폴더의 실행 파일을 사용하세요.

메모·목록·패널은 작업 표시줄에 표시하지 않습니다. 트레이 아이콘에서 목록·설정·종료를 사용할 수 있습니다. Windows 설정에 따라 아이콘이 숨겨진 아이콘 영역에 있을 수 있습니다.

## 전체 조작과 정돈

- **실행 순간 앞으로:** 모두 보이기·모두 접기·모두 펼치기·접어서 정돈·펼쳐서 정돈은 표시 대상 메모를 일반 창 앞으로 가져옵니다. 이미 같은 상태여도 동작하며 압정 설정은 유지합니다. 다른 앱의 ‘항상 위’ 창보다 위에 고정하지는 않습니다.
- **모두 접기 / 모두 펼치기:** 각 메모의 현재 왼쪽 위에서 상태만 변경합니다. 페이지를 해제하고 모든 대상 메모를 표시하며 겹침을 허용합니다. 펼칠 때 화면 밖으로 나가면 필요한 만큼만 보정합니다.
- **모두 숨기기 / 모두 보이기:** 접힘·위치·크기·압정 상태와 페이지 구성·현재 페이지를 그대로 유지하며 표시 여부만 바꿉니다.
- **접어서 정돈:** 현재 보이는 메모를 모두 36×36 DIP 타일로 접고, 모니터별 타일 시작점·배치 형태·간격·순서로 정리합니다.
- **펼쳐서 정돈:** 보이는 메모를 모두 펼쳐 모니터별 선택한 모서리에서 배치합니다. 마지막 정돈 순서를 재실행 후에도 유지하며 신규 메모는 현재 기준으로 뒤에 추가합니다. 공간이 부족하면 겹치지 않는 페이지로 나눕니다. 패널의 이전·다음으로 이동하며 패널을 닫으면 작은 페이지 조작 창을 제공합니다. 다른 페이지 메모의 저장된 표시 상태는 유지합니다. 압정 상태는 유지합니다.
- 숨긴 메모와 휴지통은 제외합니다. 타일 공간이 부족하면 들어가는 타일만 이동하고 나머지는 유지하며 안내합니다.
- 타일을 클릭하거나 Enter/Space를 누르면 **그 자리에서** 펼칩니다. 가장자리에서는 같은 화면 안으로 필요한 만큼 보정합니다. 다시 접으면 현재 펼친 창의 왼쪽 위에 타일이 남습니다. 다른 메모는 움직이지 않습니다.
- 입력하거나 드래그해도 자동 재배치하지 않습니다. 기존 자동 정렬·이전 배치 복원·접힌/펼친 메모별 정돈 명령은 제거했습니다.

## 패널과 설정

미니 패널은 새 메모·목록/검색, 모두 접기·모두 펼치기, 모두 숨기기·모두 보이기와 접어서 정돈·펼쳐서 정돈을 제공합니다. **색상별 조작**을 펼치면 선택 색상의 보이는 메모만 접거나 펼칠 수 있습니다. 색상 칩은 보이는 메모 수를 표시하고, 버튼 툴팁에는 현재 지정된 단축키를 함께 표시합니다. 색상별 동작은 전체 정돈하지 않습니다. 헤더에서 압정·설정·닫기를 사용할 수 있고 제목을 드래그하면 패널을 옮깁니다.

설정은 `배치 / 단축키 / 일반 / 백업 / 도움말 / 버전`으로 나뉩니다. 배치에는 **접어서 정돈 / 펼쳐서 정돈 / 공통**을 모았습니다. `여러 줄로 배치`는 한 줄을 채우고 다음 줄로 넘어가며, 가로·세로 한 줄은 줄바꿈하지 않습니다. 여러 줄 배치의 `한 줄에 놓을 메모 수`는 자동 또는 1~30개를 지정합니다. 자동은 시작점 오른쪽의 가용 폭으로 계산합니다. 색상순이면 새 색에서 줄을 바꾸고 같은 색은 먼저 만든 순서입니다.

`화면에서 지정`으로 시작점을 고르고, 세부 조정에서 X·Y를 입력합니다. 미리보기 버튼은 별도 창을 열며 적용 전 설정과 보이는 메모를 반영합니다. 실제 메모를 움직이지 않습니다. **적용은 설정만 저장**합니다. 일반 탭에서 로그인 자동 실행을 적용하고, 백업 탭의 백업·복원 버튼은 즉시 실행합니다.

트레이에서는 새 메모, 목록, 모두 숨기기, 모두 보이기, 미니 패널, 설정, 종료를 제공합니다. 미니 패널을 누르면 한 번에 표시하고 앞으로 가져옵니다. 패널은 항상 100% 불투명하게 표시합니다. 정돈은 패널 버튼이나 통합 단축키를 사용하세요.

## 새 메모 위치

새 메모는 같은 모니터의 보이는 같은 색 메모 중 마지막 메모 오른쪽에 펼쳐 생성하고 바로 입력할 수 있습니다. 오른쪽 공간이 부족하면 같은 색 묶음의 다음 줄과 화면 안의 빈자리를 찾고, 빈자리가 없으면 화면 안에서 계단식으로 겹칩니다. 기존 메모는 움직이지 않습니다. 같은 색 메모가 없으면 설정한 타일 시작점에서 시작합니다.

메모의 ＋·Ctrl+N은 원본 색을, 패널에서는 선택 색을, 트레이·목록·전역 단축키에서는 마지막 활성 메모 색을 사용합니다. 패널의 `전체`는 마지막 활성 메모 색을 따릅니다. 활성 메모 기록이 없으면 노랑입니다. 원본 메모에서 생성하면 해당 모니터를 사용하고, 나머지는 마지막 활성 메모의 모니터 또는 마우스가 있는 모니터를 사용합니다.

## 단축키

| 동작 | 기본 키 |
|---|---|
| 새 메모 | Ctrl+Alt+Shift+N |
| 목록·검색 | Ctrl+Alt+Shift+F |
| 현재 메모 접기·펼치기 | Ctrl+Shift+Space |
| 모두 숨기기·보이기 | Ctrl+Alt+Shift+H |
| 모두 접기·모두 펼치기 | Ctrl+Alt+Shift+C |
| 접어서 정돈 | 미지정 |
| 펼쳐서 정돈 | 미지정 |
| 미니 패널 열기·닫기 | Ctrl+Alt+Shift+P |

전환 명령은 보이는 메모 중 펼친 것이 하나라도 있으면 현재 위치에서 모두 접고, 모두 접혔으면 모두 펼칩니다. 패널에서는 원하는 동작을 두 버튼으로 직접 선택할 수 있습니다. 앱 내부 Ctrl+N·Ctrl+F는 유지합니다.

설정 v6으로 이관하면서 기존 파일을 `layout.json.pre-v6.bak`으로 보관합니다. 전체 접기·펼치기 전환 키는 이제 정렬하지 않으며 변경 안내를 한 번 표시합니다. 유지되는 키의 사용자 지정과 해제 상태를 보존하며 목록·검색은 기존 검색 키를 우선합니다. 제거된 개별 명령의 단축키는 해제하고 다른 동작에 재할당하지 않습니다.

## 편집과 데이터 보호

일반 텍스트·한글·복사/붙여넣기·실행 취소/다시 실행을 지원합니다. 프리텐다드·나눔고딕·나눔명조·나눔손글씨 펜은 앱에 포함되어 별도 설치 없이 사용할 수 있습니다. 설치된 글꼴 검색과 미리보기도 제공합니다. [글꼴 출처와 라이선스](docs/third-party-fonts.md)를 참고하세요. 메모 메뉴에서 글꼴과 10~32 1단위 및 36·40·48·56·64·72 크기·색상을 선택하고 압정 아이콘으로 항상 위를 설정합니다. 제목은 본문의 첫 비어 있지 않은 줄입니다. X는 숨기기이며 삭제는 휴지통으로 이동합니다. 목록의 체크박스와 우클릭으로 여러 메모를 관리할 수 있습니다. 휴지통 이동 후 목록·패널 또는 작은 안내 창에 10초간 실행 취소를 제공합니다. 안내 위에 마우스나 키보드 포커스가 있으면 만료를 잠시 멈춥니다. 가장 최근 삭제 묶음만 되돌리며 재실행 후에는 유지하지 않습니다. 성공적으로 삭제된 항목의 표시·접힘 상태와 위치를 복구하고, 복원 실패 항목은 다시 시도할 수 있습니다.

상단의 빈 곳이나 타일을 드래그하면 화면·다른 메모 가장자리에 자석처럼 붙으며, 더 끌면 떨어집니다. 화면 밖에 일부 걸치거나 다른 모니터로 옮길 수 있습니다.

데이터는 `%LOCALAPPDATA%\MemoitPersonal\notes.db`에 저장하며 실행 파일과 분리됩니다. DB v3은 접힌/펼친 위치를 저장합니다. 구버전 DB는 안전 백업 후 트랜잭션으로 이관하며 구버전 실행 파일로 새 DB를 열 수 없습니다. 설정 v6는 모니터별 정돈 순서와 간소화된 단축키를 저장합니다.

입력 중 약 500ms 대기 또는 최대 2초 간격으로 자동 저장합니다. 일괄 전환은 화면에 먼저 반영한 뒤 한 트랜잭션으로 저장하며 입력·드래그를 막지 않습니다. 실패 시 빨간 상태 표시와 오류를 남기고 저장 실패가 있을 때만 트레이에 나타나는 `저장 다시 시도`로 재시도합니다. 강제 종료 직전 미저장 입력까지 보장하지 않습니다.

하루 첫 저장 후 자동 백업하며 최근 7개를 보관합니다. 수동 복원은 현재 데이터 안전 백업 후 전체 교체합니다. 휴지통은 자동 삭제하지 않습니다. 데이터와 백업은 암호화되지 않습니다.

## 개발과 검증

Windows 11 x64 / .NET 10 SDK를 사용합니다.

```powershell
$env:PATH="$PWD\.tools\dotnet;$env:PATH"
$env:DOTNET_CLI_HOME="$PWD\.dotnet-home"
dotnet restore Memoit.slnx
dotnet test Memoit.slnx -c Release --no-restore
dotnet publish src/Memoit/Memoit.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o artifacts/OmniMemo-1.12.2/win-x64
```

`OMNIMEMO_DATA_DIR`로 개인 데이터와 격리하여 실행할 수 있습니다. 검증 스크립트는 테스트 데이터와 자체 실행 프로세스만 사용합니다.

```powershell
powershell.exe -NoProfile -STA -File scripts/BatchTransitionSmoke.ps1 -Executable artifacts/OmniMemo-1.12.2/win-x64/OmniMemo.exe -ShowOverlay
powershell.exe -NoProfile -STA -File scripts/InputDragSmoke.ps1 -Executable artifacts/OmniMemo-1.12.2/win-x64/OmniMemo.exe -ShowOverlay
powershell.exe -NoProfile -STA -File scripts/NewNoteFontsSmoke.ps1 -Executable artifacts/OmniMemo-1.12.2/win-x64/OmniMemo.exe
dotnet run --project scripts/ArrangementVerification -c Release -- --output artifacts/verification/arrangement-final-1.12.json
```

이전 1.10 검증: 단위/STA 테스트 221개와 Release 게시 빌드 통과. 같은 색 타일 옆 생성, 연속 생성, 원본·패널·최근 활성 색상 상속, 입력 포커스, 포함 글꼴 4종과 설치 글꼴 검색 선택을 실제 실행 파일에서 확인했습니다. 위치 계산은 음수 좌표·100/150/200% 배율·화면 부족·크기 제한을 자동 테스트했습니다. 포함 글꼴의 실제 한글 글리프와 DB 저장 왕복도 확인했습니다.

이전 1.9 검증: 단위/STA 테스트 206개, Release 빌드 통과. 실제 실행 파일에서 4개 설정 탭, 별도 미리보기의 단일 창·재열기·부모 닫기, 6개 단축키, 불투명도 적용, 적용 시 메모 위치 유지, 삭제 실행 취소, 입력·자동 저장·창 이동과 일괄 전환을 확인했습니다. 트레이의 간소화 메뉴와 숨김/보임 전환도 확인했습니다.

100/150/200% 설정 화면 오프스크린 렌더링을 확인했습니다. 실제 물리 다중 모니터·배율 전환, 한글 IME 조합은 미검증입니다. 자석 드래그 정밀 좌표 검사는 기대 좌표와 차이가 있어 통과하지 못했습니다. 저장 실패 재시도 메뉴의 실제 복구 검사는 중복 트레이 아이콘으로 테스트 앱을 안전하게 식별할 수 없어 완료하지 못했습니다. 저장 실패·재시도 상태와 설정 복구 로직은 자동 테스트로 검증했습니다.

동기화·이미지·일정 알림·부분 글자 서식은 포함하지 않습니다. 소스의 Memoit 네임스페이스는 호환성을 위해 유지합니다.


## 1.11 변경 사항

- 메인 목록은 활성 메모만 표시하고 휴지통은 별도 창으로 엽니다.
- 전체 펼치기는 모든 대상 메모를 겹치지 않는 페이지에 배치합니다. 목록에서 메모를 열면 해당 페이지로 이동합니다.
- 미니 패널은 항상 100% 불투명하게 표시합니다.

## 1.11.1 검증

- 단위/STA 테스트 233개 통과. 페이지별 겹침 방지, 목록 새로고침, 휴지통 검색·선택·동작 연결과 불투명도 제거를 검사했습니다.
- 격리된 데이터의 실제 WPF 창으로 100개 메모 페이지 전환, 목록 열기, 전체 접기·숨김·보임, 입력·드래그, 페이지 재구성, 휴지통 창 재사용을 검증했습니다.
- 단일 1920×1032 작업 영역·100% 배율에서 타일 100개와 메모 20개의 전환을 측정했습니다. 결과는 docs/verification-1.11.1.md에 기록합니다.
- 실제 물리 다중 모니터, 배율 전환, 한글 IME 조합, 모든 메뉴의 수동 클릭 및 흰색 깜빡임의 육안 검사는 이번 검증에 포함하지 못했습니다.

## 1.11.2 변경 사항

- 전체 메모 새로고침은 버튼 문구나 완료 알림을 바꾸지 않습니다.
- 휴지통의 제목·삭제 날짜·작업 버튼을 분리하고 긴 제목을 말줄임 처리합니다.
- 휴지통 비우기는 검색 결과와 관계없이 모든 삭제된 메모를 대상으로 합니다. 전체 개수와 복구 불가 안내를 한 번 확인하고, 취소가 기본값입니다.
- 236개 테스트 통과. 기본/최소 폭 렌더링에서 버튼 배치와 긴 제목 처리를 확인했습니다.

## 1.11.3 변경 사항

- 메모 상단 접기 버튼과 현재 메모 접기 단축키는 펼친 창의 현재 위치에 타일을 남깁니다.
- 이전 정돈 위치는 직접 접기에서 사용하지 않습니다. 접어서 정돈을 실행한 경우에만 설정된 정렬 위치로 이동합니다.
- 직접 접기 위치 저장·왕복 회귀 테스트를 추가했습니다. 전체 테스트 237개 통과.

## 1.11.4 변경 사항

- 설정에 도움말·버전 탭을 추가했습니다. 도움말은 직접 접기와 정돈의 차이, 페이지 이동, 숨김·휴지통, 기본 단축키, 저장·복구 방법을 안내합니다.
- 버전 탭은 실행 중인 프로그램의 버전과 최근 변경 내역을 표시합니다. 두 안내 탭에서는 적용 버튼을 숨깁니다.

## 1.12.0 변경 사항

- 현재 위치에서 접기·펼치기와 설정 위치로 정돈하는 명령을 분리했습니다.
- 패널의 전체 조작·정돈 구획과 단축키 8개, 설정·도움말 명칭을 통일했습니다.
- 압정은 켜졌을 때 청록색으로 채워 표시하고 제목 드래그와 클릭 영역을 분리했습니다.
- 숨김·보임은 페이지 구성과 현재 페이지를 유지하며 위치를 다시 계산하지 않습니다.
검증: 전체 단위·STA 테스트 243개, Release 빌드, 실제 WPF 창 통합 검증 통과. 혼합 접힘 상태의 무변경, 숨김·휴지통 제외, 다른 페이지 대상 처리, 개별 접기 후 페이지 분리, 숨김/보임의 좌표·페이지 유지, 압정 저장·복원을 확인했습니다.

1920×1032 작업 영역·100% 배율에서 화면 반영은 타일 100개 정돈 45~99ms, 메모 20개 접기 56~90ms, 펼치기 162~214ms였습니다. 펼치기 6회 중 2회는 200ms 목표를 초과했습니다. 100개 펼쳐서 정돈·페이지 구성은 234ms였습니다.

실제 마우스 클릭·드래그 시연은 화면 제어 도구가 검증 앱의 창을 찾지 못해 완료하지 못했습니다. 압정의 영역·채움·토글은 STA 테스트, 저장·재실행 복원은 WPF 통합 테스트로 확인했습니다. 실제 물리 다중 모니터·150/200% 배율과 한글 IME 입력은 이번 릴리스에서 추가 검증하지 못했습니다.

## 1.12.1 변경 사항

- 설정 화면을 카드·탭 중심으로 재구성하고 여백·입력란·모서리 선택·적용 영역을 통일했습니다.
- 단축키를 구획별 카드로 묶고 드롭다운을 저대비 스타일로 개선했습니다. 저장·배치 계산은 유지합니다.

## 1.12.2 변경 사항

- 전체 표시·접기·펼치기·정돈 명령을 실행하면 대상 메모를 앞으로 가져옵니다. 접기·펼치기의 현재 위치 유지와 정돈의 배치 변경을 구분합니다.
- 자동 저장 후 숨겨진 목록 재생성을 없애고 여러 메모의 저장 알림을 한 번의 화면 갱신으로 합칩니다. 변하지 않은 색상 버튼·페이지 선택기도 유지합니다.
- 긴 본문의 제목 계산에서 전체 줄 복사를 제거하고, 제목 캐시와 저장 상태 변경 알림을 개선했습니다.
- 전체 테스트 253개와 실제 WPF 통합 검증 통과. 700줄 본문 20개를 띄운 12초 편집·자동 저장 측정에서 최대 UI 응답 간격 165ms, 1초 이상 멈춤 없음. 사용자 환경 전체의 끊김 해소를 보장하는 수치는 아닙니다.
- 분리된 검증 앱에서 실제 패널 접기·펼치기 클릭과 타일·긴 본문 화면을 확인했습니다. 자세한 범위와 한계는 [검증 기록](docs/verification-1.12.2.md)을 참고하세요.
